# Open WebUI Desktop AVX1

[Upstream](https://github.com/open-webui/desktop) · [NSIS EXE](https://github.com/aktalascloud/open-webui-desktop-ivybridge-avx1/releases/latest) · [Applied patches](patches/README.md)

Build with Python 3.12+, Git and GitHub CLI: `Build.cmd status`, then `Build.cmd build`. CI and checks are in `.avx1/`. Keep user data, model weights and credentials outside the source checkout.

Русский интерфейс, изоляция подключений, голосовые сочетания и проверенный AVX PTY. WebUI и Terminal запускаются отдельными сервисами.
