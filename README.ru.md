# Open WebUI Desktop · Ivy Bridge AVX1

[English](README.md) · [Русский](README.ru.md)

Одна актуальная сборка из свежих официальных исходников и проверенных патчей. Дополненный русский перевод интерфейса, системного трея и контекстных меню.

Скачайте **EXE-установщик** из последнего релиза и запустите его. Установщик поддерживает выбор папки и повторную установку поверх прежней версии. Профиль, данные и модели хранятся отдельно от файлов программы. Desktop и установка backend используют проверенные форки владельца.

[Upstream](https://github.com/open-webui/desktop) · [Releases](https://github.com/aktalascloud/open-webui-desktop-ivybridge-avx1/releases)

## Патчи

| ID | Изменение |
|---|---|
| DESK-001 | Сохранены профиль, название и оформление Open WebUI. |
| DESK-002 | node-pty пересобирается с AVX и LTCG для Ivy Bridge. |
| DESK-003 | Electron 45; совместимость с независимо запущенным backend. |
| DESK-004 | Исправлены типы и освобождение обработчиков. |
| DESK-005 | Обычный EXE-установщик; проверенные обновления Desktop и оптимизированного backend из форков. |
| DESK-006 | Полный русский интерфейс, трей и контекстные меню; проверка установленной программы. |

Производительность GUI и LLM в процентах не измерялась. Нативный терминал проверяется на настоящем Xeon E5-2697 v2. PGO отключён; Electron и Python используют сборки поставщиков.

Оригинальные лицензии и notices сохранены; точный исходный код доступен по тегу каждого релиза. Закрытый код фильтра, бриджа, настройки, журналы и модели не публикуются.
